# Profile photos (dummy / dev)

Place profile images here to show on discovery cards and full profile view.

**Folder location:**  
`public/profile-photos/`  
(or `prom-connect/public/profile-photos/` from repo root)

**File names (use exactly these):**

| File       | Profile |
|-----------|---------|
| `p1.jpg`  | Priya   |
| `p2.jpg`  | Arjun   |
| `p3.jpg`  | Riya    |
| `p4.jpg`  | Vikram  |
| `p5.jpg`  | Ananya  |

You can use `.jpg`, `.jpeg`, or `.png` (e.g. `p1.png`).  
If a file is missing, the app shows the profile initial (letter) instead.
